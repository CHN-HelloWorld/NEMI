Hunting Mode Guide

When hunting mode is enabled, green debug text will appear at the top of the screen.
Set hunting = 2 in d3dx.ini, then press [Numpad 0] to toggle.

Numpad Shortcuts:
[Numpad 1/2]: Cycle previous/next Pixel Shader (PS)
[Numpad 3]:   Mark current Pixel Shader
[Numpad 4/5]: Cycle previous/next Vertex Shader (VS)
[Numpad 6]:   Mark current Vertex Shader
[Numpad 7/8]: Cycle previous/next Index Buffer (IB)
[Numpad 9]:   Mark current Index Buffer
[Numpad //*]: Cycle previous/next Vertex Buffer (VB)
[Numpad -]:   Mark current Vertex Buffer
[Numpad +]:   Finish hunting, re-enable all shaders

[Numpad .]+[1/2]: Cycle previous/next Compute Shader (CS)
[Numpad .]+[3]:   Mark current Compute Shader

Once marked, the hash value will be copied to the clipboard.
Paste the hash value into the [ShaderOverride] or [TextureOverride] section of the Mod.

[F8]: Frame Analysis - Dump all render targets/buffers of the current frame
Dump files will be saved in the FrameAnalysis-XXXX folder.

Press [Ctrl]+[F12] to hide this guide.
