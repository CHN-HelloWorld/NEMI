NTE Engine Mod Importer (NEMI)

Mod Installation:
1. Extract the Mod archive.
2. Place the extracted folder into the Mods folder.

Mod Hot Reload (No game restart required):
1. Install the Mod.
2. Move the affected character off-screen (switch to another character).
3. Press F10 to reload NEMI.

User Shortcuts:
[F12]: Toggle this user guide display.
[F6]: Toggle NEMI Mods ON/OFF.
[F10]: Reload NEMI and save Mod settings.
[Alt]+[F12]: Toggle legacy compatibility mode.
[Ctrl]+[Alt]+[F10]: Reset Mod settings and reload.

Developer Shortcuts:
[F9]: Hold to temporarily disable NEMI.
[Ctrl]+[F9]: Toggle Performance Monitor.
[Ctrl]+[F12]: Toggle Hunting Mode Guide.
[Numpad 0]: Toggle Hunting Mode (green text, requires hunting = 2 in d3dx.ini).

Notes:
- Ensure d3d11.dll is in the same directory as 3DMigoto Loader.exe.
- Run 3DMigoto Loader.exe first before launching the game via the official launcher.
- The target game process name is configured in d3dx.ini under [Loader] > target.
