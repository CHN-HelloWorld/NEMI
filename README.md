NEMI is a runtime shader and graphics injection framework.

## Project Status

This is an immature project and currently only provides de-obfuscation functionality. Development based on this version is not recommended.

However, if you still want to maintain it, contributions are always welcome.

Please wait for updates from XXMI or other developers for an official release. This version is only a temporary remedy for in-game obfuscation and may stop being maintained at any time.

## Usage

1. Double-click Start.cmd, then launch the game with the official launcher.
2. Press F7 to enable or disable de-obfuscation.
